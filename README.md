# 浮岛书签 · Visual Bookmark

一个玻璃质感、动漫浮岛背景的 Chrome 书签**整理**工具。把多个文件夹并排摊开，拖拽归位，顺手找出重复和空的文件夹。

## 功能

- **书签总览**：书签总数、书签最多的文件夹排行、最近添加、收藏最多的网站
- **整理台**：同时打开多个文件夹，并排对照；面板可切换列表 / 图标布局，可调宽窄
- **拖拽整理**（随时可用）
  - 把书签、文件夹拖到任意面板、面板里的子文件夹，或左侧文件夹树上
  - 左侧文件夹、面板标题、最近添加、搜索结果也都能直接拖
  - 从网页或地址栏把链接拖进任意文件夹，直接收藏到那里
  - 所有改动都能撤销（⌘Z / Ctrl+Z，或提示条上的“撤销”）
- **整理模式**：单击多选、Shift 连选，批量移动 / 打开 / 删除；编辑标题和网址、新建文件夹
- **整理建议**：重复书签、空文件夹、未放进文件夹的书签、没有标题的书签
- **搜索**：按 `/` 聚焦，支持标题、网址、域名，结果可一键定位到所在文件夹
- **设置**：黄昏 / 星夜两种浮岛场景，或换成自己的图片；可调玻璃透明度、模糊、背景动画、点开书签的方式

## 安装（开发者模式）

1. 打开 `chrome://extensions/`
2. 右上角打开“开发者模式”
3. 点击“加载已解压的扩展程序”，选择本项目文件夹
4. 更新代码后，在扩展卡片上点“重新加载”

## 使用

- 点击工具栏图标：快速搜索、查看最近添加，或“打开整理台”
- 在整理台里点文件夹进入，⌘ / Ctrl + 点击在新面板打开
- 随时可以拖拽移动；整理模式下单击是选择，双击才打开

## 权限说明

- `bookmarks`：读取和整理你的书签
- `favicon`：从浏览器本地读取网站图标，不向第三方请求

所有数据只在本机处理，不会上传到任何地方。自定义背景图片保存在本机浏览器的 IndexedDB 中。

## 项目结构

```
bookmarks.html   主页面（总览 + 整理台）
popup.html       工具栏弹窗
css/theme.css    主题、玻璃、背景场景、通用组件
css/styles.css   主页面布局
css/popup.css    弹窗布局
js/app.js        主页面交互（面板、拖拽、选择、弹窗）
js/store.js      书签数据层与可撤销的写操作
js/scene.js      浮岛背景场景与自定义壁纸
js/icons.js      图标与文件夹色块
js/util.js       通用工具函数
js/popup.js      弹窗逻辑
```

纯 HTML / CSS / JavaScript，无外部依赖。
