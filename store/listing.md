## 0. 上传的文件

## 1. 商品详情（Store listing）

**名称**（来自 manifest，无需填写）：浮岛书签 Visual Bookmark

**摘要**（来自 manifest）：玻璃质感的可视化书签整理工具：多个文件夹并排打开，拖拽归位，找出重复书签。

**说明**：

```
浮岛书签是一个可视化的书签整理工具。

书签一多，Chrome 自带的书签管理器一次只能看一个文件夹，挪来挪去很费劲。浮岛书签把多个文件夹并排摊开，直接拖拽就能归位。

主要功能
● 整理台：同时打开多个文件夹并排对照，支持列表和图标两种布局
● 拖拽移动：书签和文件夹可以拖到任意面板、子文件夹，或左侧文件夹树
● 拖链接收藏：把网页上的链接或地址栏里的网址拖进文件夹，直接收藏到那里
● 批量整理：多选后一起移动、打开或删除；编辑标题和网址，新建文件夹
● 随时撤销：每一次移动、编辑、删除都可以撤销
● 整理建议：找出重复书签、空文件夹、没放进文件夹的书签和没有标题的书签
● 快速搜索：按 / 搜索标题、网址和域名，一键定位到所在文件夹
● 书签总览：书签最多的文件夹、最近添加、收藏最多的网站
● 界面：玻璃质感，黄昏和星夜两种动漫浮岛背景，也可以换成自己的图片

隐私
所有书签只在你的电脑上读取和处理，不上传、不收集任何数据，也不加载任何远程代码。网站图标来自 Chrome 内置的本地图标服务。
```

**类别**：工具（Productivity › Tools）

**语言**：中文（简体）

**图片**（都在 `store/` 文件夹里）：

| 后台里的位置 | 文件 |
|---|---|
| 商店图标 128×128 | `store/store-icon-128.png` |
| 屏幕截图 1280×800（1–5 张） | `store/screenshots/1-overview.png` … `4-night.png` |
| 小型宣传图块 440×280 | `store/promo-small-440x280.png` |
| 顶部宣传图块 1400×560（可选） | `store/promo-marquee-1400x560.png` |

**官方网址 / 支持网址**（可选）：https://github.com/Freedomshine/chromevisualbookmark

## 2. 隐私权（Privacy）

**单一用途说明**：

```
在一个页面里可视化地浏览和整理 Chrome 书签：多个文件夹并排显示，通过拖拽来移动、编辑和删除书签。
```

**bookmarks 权限的理由**：

```
这是扩展的核心功能：读取书签树并显示出来；在用户主动拖拽、编辑、删除或新建时修改对应的书签。所有处理都在本地完成，不会上传。
```

**favicon 权限的理由**：

```
使用 Chrome 内置的 _favicon 服务在本地显示每个书签的网站图标，避免把用户收藏的网址发给第三方图标服务。
```

**是否使用远程代码**：否，我不使用远程代码（所有 JavaScript 都打包在扩展里）。

**数据使用**：不勾选任何数据类型（不收集任何用户数据）。下面三条声明全部勾选：

- 我不会将用户数据出售或转让给第三方，已获批准的使用情形除外
- 我不会将用户数据用于与商品单一用途无关的目的或转让用于此类目的
- 我不会为确定信用度或发放贷款而使用或转让用户数据

**隐私权政策网址**：https://github.com/Freedomshine/chromevisualbookmark/blob/master/PRIVACY.md

## 3. 分发（Distribution）

- **付款**：免费
- **公开范围**：
  - 只给自己的几台电脑用：选“不公开”（Unlisted），有链接的人才能安装，搜索不到
  - 想让别人也能搜到：选“公开”（Public）
- **分发地区**：所有地区

## 4. 提交

点“提交审核”。审核通常几天内完成，新开发者和第一次提交可能更久。通过后，在每台电脑的 Chrome 里打开商品链接，点“添加至 Chrome”。登录同一个 Google 账号并开启同步后，其他电脑会自动装上，以后也会自动更新。

装好商店版后，记得在 `chrome://extensions` 里删掉之前用开发者模式加载的那一份，免得两个同时存在。
